# CS Ticket + Vercel

## Description
A customer service ticketing platform to help clients reports. Originally from CS Ticket + PHP + MongoDB project from mcqeems, Adjusted for vercel deployment.

## Pre-requisites
You need a `.env` file that contains:
```
MONGODB_URI='<MongoDB_URI>'
MONGODB_DATABASE='<Database_Name>'
```
Make sure to place it in the root folder.

> Disclaimer: You might need to read the original documentation of this project to learn more if there's something wrong.

## Deployment
When everything is covered and you confidence that all of the configs is right, you can deploy it right away at vercel. Remember to import your .env.

Original Repo: [cs-ticket-php](https://github.com/mcqeems/cs_ticket_php)
